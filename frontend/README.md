# NovelBridge frontend

Vite + React + TypeScript + Tailwind v4 + shadcn/ui. In development the Vite server proxies
`/api` to the FastAPI backend on port 8000, so start the backend first.

```powershell
npm install
npm run dev      # http://localhost:5173
npm run build    # typecheck + production build
```

See the [top-level README](../README.md) for the full stack, configuration, and API contract.
